# Analytical Results: Charts Directory

This directory stores publication-quality figures and visual exhibits generated for the final presentation and business reports:

* `vehicle_visibility_proxy.png`: Distribution of candidate EV visibility signals across Adey Market and Gezat Electric.
* `category_prioritization_matrix.png`: Scatter plot mapping Wear Velocity against Freight Bulkiness / Sourcing Difficulty.
* `sensitivity_stability_heatmap.png`: Heatmap visualizing rank stability across alternative weighting scenarios.
* `top_5_recommendation_breakdown.png`: Stacked bar chart showing the composite score breakdown (5 pillars) for the Top 5 prioritized parts.

*Files are generated programmatically via matplotlib/seaborn.*
