# Analytical Results: Rankings Directory

This directory stores exported CSV tables generated by the scoring engine and sensitivity simulations:

* `baseline_top_parts_ranking.csv`: The complete ranked list of all evaluated parts under the baseline 5-pillar weighting model.
* `sensitivity_scenario_rankings.csv`: The cross-scenario ranking matrix comparing part positions across Baseline, Wear-Aggressive, Capital-Preserving, Compatibility-Focused, and Scarcity-Constrained models.

*Files are generated programmatically via `notebooks/03_prioritization_scoring.ipynb` and `notebooks/04_sensitivity_analysis.ipynb`.*
